# benj.bid

A creative business card: fly through space, land on Earth, and wander a dreamy 3D meadow. There are ten secrets hidden in the grass.

Built with [Astro](https://astro.build) and [three.js](https://threejs.org). Everything is procedural: no textures, no audio files.

```bash
npm install
npm run dev      # http://localhost:4321  (add ?skip to jump past the intro)
npm run build
```

Edit the card in `src/data/site.ts`. Pushing to `main` deploys to GitHub Pages.
